# 噜噜我们 travel 去 · 旅程记录小程序

一款微信小程序，支持**单人记录**与**双人共享**：一个人可以记录自己的旅行，也可以连接一位同行者（朋友、情侣都可以），共用同一个空间记录共同的旅程。

不做攻略推荐，只解决一件事 — 把一趟旅行，从想去、准备、在路上到回来之后，完整地记下来。

## 产品结构

按旅程全周期设计，五个阶段互相回流：

| 阶段 | 功能 |
| --- | --- |
| 想去 | To Go List：愿望地点、期望时间、标签与意愿度 |
| 规划 | 旅游攻略：基础安排（住宿 / 出行 / 美食 / 打卡 / 其他）+ 按天行程 |
| 准备 | 必带清单：分类预置、勾选准备状态，未完成数回流旅程页提醒 |
| 记录 | 花销记账与分类统计、高光记录（文字 + 照片记下旅途瞬间） |
| 回忆 | 基于高光瞬间自动生成旅行日记初稿（可编辑、可重新生成）；首页汇总年度足迹与地图点亮 |

## 核心设计

- **空间模型先行**：数据先归属个人空间，连接同行者后升级为双人共享 — 新增、修改、断开都有明确规则
- **旅程中枢**：每趟旅程有自己的主页与状态（进行中 / 已完成），未完成事项聚合提醒
- **AI 的边界**：AI 只负责把用户记录的瞬间整理成文，出初稿；编辑与最终决定权在人
- **验证**：双账号真机交叉测试（两端一致、重复编辑、删除不复活、断开不可见），已发布体验版 v0.2.0
